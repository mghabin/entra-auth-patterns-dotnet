# Contributing

Thanks for your interest in this sample. It exists to demonstrate Entra ID
(formerly Azure AD) auth patterns in a small, opinionated .NET monorepo.
Issues and PRs that sharpen the demonstrations or fix bugs are very
welcome; PRs that broaden the sample into a fuller product are usually
not (the smaller it stays, the more it teaches).

## Ground rules

- One concern per PR. If a refactor and a feature want to ship together,
  split them.
- All PRs must pass the `ci` workflow (`build-test`) and CodeQL.
- All PRs must keep `dotnet format --verify-no-changes` green.
- Branch names follow conventional-commits-ish prefixes:
  `feat/…`, `fix/…`, `test/…`, `docs/…`, `chore/…`, `refactor/…`.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/):
  `<type>(<scope>): <summary>` with a wrapped body explaining *why*.
- Squash-merge only — `main` keeps a linear history and is force-push
  protected.

## Local prerequisites

- .NET SDK pinned in `global.json` (use `dotnet --version` to confirm).
- `az` CLI for the `scripts/setup-entra.{sh,ps1}` flows.
- `openssl` if you plan to (re)generate the AccountingService cert.

## Build, test, format

```bash
dotnet restore EntraAuthPatterns.slnx --locked-mode
dotnet build   EntraAuthPatterns.slnx --configuration Release --no-restore
dotnet test    EntraAuthPatterns.slnx --configuration Release --no-build
dotnet format  EntraAuthPatterns.slnx --verify-no-changes
```

NuGet uses central package management (`Directory.Packages.props`) plus
`packages.lock.json` per project. Bump versions in CPM only — the lock
files are regenerated by `dotnet restore`.

## Adding a new auth pattern

1. Add a `Ftgo.<Pattern>Service` project under `src/`.
2. Implement `IAppTokenProvider` from `Ftgo.Auth.Client` if it acquires
   tokens; otherwise use `AddEntraAuth` if it validates them.
3. Update `docs/sample-setup.md` with the new app registration or
   federated credential. Keep the table in `docs/run-locally.md` in sync.
4. Add tests in `tests/Ftgo.Auth.Tests/` that exercise the wiring (the
   existing `AddEntraAuthWiringTests` is the template).
